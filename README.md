# Block Blast Docs

Block Blast Docs is a community-maintained knowledge base focused on gameplay mechanics, puzzle strategies, troubleshooting, and technical reference material for Block Blast players.

The goal of this project is to organize practical information into a structured documentation format that is easy to browse, maintain, and improve over time.

## What you'll find

- Gameplay fundamentals
- Board management strategies
- Puzzle-solving concepts
- Installation and compatibility references
- Troubleshooting guides
- Frequently asked questions
- Version notes
- Additional learning resources

## Documentation

The published documentation is available through GitHub Pages.

## Project Philosophy

This repository focuses on educational documentation rather than news or entertainment. Articles are written to explain concepts, document common issues, and provide reference material that helps players better understand the game.

Whenever possible, information is organized into reusable documentation instead of temporary blog posts.

# Contributing

Thank you for helping improve Block Blast Docs.

## Ways to Contribute

Contributions may include:

- Documentation improvements
- Grammar corrections
- Clarifications
- Additional gameplay references
- Navigation improvements
- New diagrams
- Reference material

## Before Submitting

Please ensure that contributions:

- Are accurate.
- Improve readability.
- Avoid duplicate information.
- Follow the existing documentation style.

Small improvements are always welcome.

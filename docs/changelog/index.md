# Changelog

This section records meaningful updates made to the documentation project.

Unlike a blog, the changelog focuses on structural improvements, new reference material, expanded documentation, and maintenance work.

---

## Purpose

The changelog helps contributors and readers quickly understand how the documentation evolves over time.

Typical updates include:

- New documentation pages
- Expanded gameplay references
- Updated troubleshooting information
- Navigation improvements
- Additional diagrams
- Dataset updates
- Documentation corrections

---

## Documentation Philosophy

The goal of this project is to improve existing reference material rather than continuously publish short articles.

Whenever possible, updates expand or improve existing documentation instead of creating duplicate content.

# Compatibility Reference

Compatibility can vary between devices depending on hardware, operating system version, and available system resources.

This reference explains common compatibility factors without focusing on any single manufacturer or device.

---

## Operating System

Keeping the operating system reasonably up to date improves compatibility and helps reduce unexpected installation issues.

Older operating system versions may not support newer application features.

---

## Device Storage

Insufficient storage is one of the most common reasons installations fail.

Before installing:

- Verify available storage.
- Remove unnecessary files if needed.
- Restart the device after freeing space.

---

## Performance

Gameplay performance may be affected by:

- Limited available memory
- Background applications
- Battery optimization settings
- Device age
- Thermal throttling during extended play

Closing unnecessary applications before launching the game often improves stability.

---

## Internet Connection

Although many gameplay features do not require a constant connection, downloading updates or installation packages generally benefits from a stable network.

Interrupted downloads may result in incomplete files.

---

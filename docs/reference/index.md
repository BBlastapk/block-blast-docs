# Reference Library

The Reference Library collects technical and gameplay reference material in one place. Unlike walkthroughs, these documents are intended to be evergreen resources that explain mechanics, terminology, and gameplay concepts.

## Categories

- Board mechanics
- Piece reference
- Gameplay terminology
- Strategy concepts
- Scoring
- Solver concepts
- Installation reference
- Compatibility reference
